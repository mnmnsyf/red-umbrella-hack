# Source assets

Full-size originals that are not shipped with the site. The app loads the compressed copies in
`public/textures/web/` (resized JPG/PNG, about 1 MB in total); regenerate those from here if an
original changes.

- `textures/`: AI-generated textures for the glass-diorama scene. `reference-key-art.png` is a
  lighting and material target only; `bezel-strip.png` and `seabed-sidescan.png` are unused.
